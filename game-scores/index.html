Game Night Scores

Pick a game to keep score. Each game remembers its own scores on this device, so you can switch between them.

Games with a camera button can read scores from a photo. You check the result before it is added.

Photo scoring

In the downloaded app, photos are read by Claude using your own Anthropic API key. Each photo costs a few cents, billed to that key. Without a key everything else works; you enter scores by hand.

Create a key at console.anthropic.com → API keys. It is stored only on this device.
